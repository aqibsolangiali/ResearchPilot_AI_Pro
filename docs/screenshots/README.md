# Add genuine screenshots to your README

The README currently references screenshot filenames inside an HTML comment to avoid broken images. Capture real screens from a *local or secured* ResearchPilot instance, using only synthetic or public sample PDFs.

1. Open the app in Chrome (for example, the local URL `http://localhost:5173`).
2. Capture a clean 1440×900 (or similar) screenshot of the **Research workspace** and save as `dashboard.png`.
3. Capture the **AI Research Studio** after a non-sensitive search and save as `research-studio.png`.
4. Capture **Compare studies** with two public/synthetic documents and save as `comparison.png`.
5. Add the three image files to this folder in GitHub and remove the `<!--` and `-->` comment markers from the three README image lines. Each screenshot should be authentic, not an AI-generated mockup.

Do not capture API keys, private documents, emails, or identifying data. Do not upload private research PDFs to the current public backend.
